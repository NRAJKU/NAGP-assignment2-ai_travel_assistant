# Knowledge-base Source Notes

The knowledge base uses four public sources. The project keeps concise notes rather than redistributing entire pages. `source_registry.json` stores the original title and URL.

1. Visit Singapore — Official Tourism Guide
   https://www.visitsingapore.com/
   Stable destination information and practical visitor planning.

2. Visit Singapore — 24 Hours in Singapore
   https://www.visitsingapore.com/content/visitsingapore/en/travel-tips/travelling-to-singapore/itineraries/24-hours-in-singapore/
   Example of grouping attractions and experiences into a compact itinerary.

3. Visit Singapore — Singapore Itineraries
   https://www.visitsingapore.com/singapore-itineraries/
   Itinerary ideas for different traveller profiles and durations.

4. Wikivoyage — Singapore Travel Guide
   https://en.wikivoyage.org/wiki/Singapore
   Complementary district, neighbourhood and transport guidance.

The source URLs should be retained in the application output. If fetched pages are redistributed, review each source's reuse terms first.
